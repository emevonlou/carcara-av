# Sobre

O CarcaráAV é um antivírus open source desenvolvido em Python com foco em transparência, segurança e aprendizado.

Este projeto nasceu como um desafio pessoal: compreender profundamente como um antivírus funciona e construir, passo a passo, uma solução capaz de identificar ameaças de forma responsável, auditável e compreensível.

Mais do que detectar arquivos maliciosos, o CarcaráAV pretende explicar ao usuário por que uma ameaça foi identificada e quais características levaram àquela decisão.

Acreditamos que segurança também significa compreender o que acontece dentro do próprio sistema.

---

# Objetivos

O CarcaráAV busca:

- proteger sistemas de forma transparente;
- desenvolver técnicas de detecção de malware;
- estudar análise heurística;
- compreender arquitetura de antivírus;
- compartilhar conhecimento com a comunidade;
- evoluir continuamente como projeto open source.

---

# Por que criar um antivírus?

Construir um antivírus está entre os maiores desafios da programação de sistemas.

Este projeto representa uma jornada de aprendizado em diversas áreas da computação, incluindo:

- Segurança da Informação
- Engenharia de Software
- Sistemas Operacionais
- Computação Forense
- Engenharia de Detecção
- Análise de Malware
- Desenvolvimento Seguro

Cada módulo desenvolvido será também um passo importante na evolução técnica.
