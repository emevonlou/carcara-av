# Sobre

O **CarcaráAV** é um antivírus open source desenvolvido em Python, criado com um objetivo simples:

**proteger sistemas com transparência.**

Mais do que detectar ameaças, o CarcaráAV busca explicar ao usuário **o que foi encontrado, por que foi encontrado e como aquela decisão foi tomada**.

A segurança não deve ser uma caixa-preta.

Ela deve ser compreensível.

---

# Filosofia

O Carcará é uma das aves mais inteligentes e resilientes da fauna brasileira.

Ele observa antes de agir.

Analisa antes de atacar.

Essa é a filosofia deste projeto.

Cada arquivo, processo ou comportamento deve ser analisado com clareza, reduzindo falsas detecções e permitindo que o usuário compreenda seu próprio sistema.

Porque segurança também é conhecimento.

---

# Por que criar outro antivírus?

Porque aprender exige desafios.

O CarcaráAV nasceu como um projeto pessoal para estudar profundamente:

- arquitetura de antivírus;
- análise de malware;
- detecção baseada em assinaturas;
- análise heurística;
- monitoramento comportamental;
- desenvolvimento de software seguro;
- engenharia de sistemas.

Construir um antivírus é um dos maiores desafios dentro da programação de sistemas.

Este projeto representa justamente essa jornada de aprendizado.

Cada funcionalidade implementada será também uma oportunidade de compreender melhor como ameaças modernas funcionam e como podem ser combatidas de forma ética e transparente.
