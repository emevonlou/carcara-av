# CarcaráAV

CarcaráAV é um antivírus open source desenvolvido em Python com foco em transparência, privacidade e análise comportamental.

## Objetivos

- Scanner de arquivos
- Análise heurística
- Quarentena
- Monitoramento em tempo real
- Interface gráfica
- Atualização de assinaturas
